Project Overview

Developed an interactive 3D casino simulator in Unity, featuring multiple mini-games including Roulette, Blackjack, and Slot Machines.

Details

  • Implemented game mechanics and state systems using C#, ensuring accurate payout calculations and game logic progression
  • Developed a cross-scene gameplay loop allowing players to transfer earned currency from casino mini-games to an island simulation scene for purchasing and planting assets.
  • Implemented a local data persistence system using JSON to save player currency securely within the web browser.
