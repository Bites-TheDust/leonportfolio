Project Overview

A classic RTS game in Unity featuring core mechanics such as resource gathering, base building, and infantry production.

Details

  • Implemented grid-based building placement constraints using C#.
  • UI/UX Upgrade Menu using Unity UI, dynamically updating and scaling unit attributes based on progression data.
  • Integrated pathfinding systems utilizing Unity NavMesh to handle real-time unit movement and navigation.
  • Upgrade Tree System using ScriptableObjects, allowing players to permanently enhance building or unit stats using rewards earned from matches.
